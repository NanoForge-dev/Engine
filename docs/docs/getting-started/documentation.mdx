The engine documentation has two parts:

- **Guides**, in this tab: what each package is for and how to use it, with examples. Start with [Create a project](./how-to-use).
- **API reference**, in the API reference tab: every class, method, option and type of every package. It is generated from the comments in the engine source code.

Both are published from the [engine repository](https://github.com/NanoForge-dev/Engine) at each engine release, so they match the latest published packages.

## Report a mistake

If a page is wrong, unclear or missing, open an issue on the [engine repository](https://github.com/NanoForge-dev/Engine/issues), or ask on [Discussions](https://github.com/NanoForge-dev/Engine/discussions). The guides are the `.mdx` files in the repository's `docs/docs` folder: you can also propose a change there with a pull request.
