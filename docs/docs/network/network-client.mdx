# Client Networking (network-client)

This document describes how the `network-client` package connects to a `network-server` instance and the concrete APIs used from client-side code.

## Overview

A client connects to a single server instance and sends every packet on one of
four [channels](packet-framing), exposed on `ctx.network`:

- `reliableOrdered` and `reliableUnordered`, carried by a TCP WebSocket, for
  control commands such as join, play, and input.
- `unreliableOrdered` and `unreliableUnordered`, carried by WebRTC data
  channels, for server snapshots or low-latency updates.

## Example

It works the same on every channel:

```javascript
// Wait for connection to be established
async function waitForConnection() {
  if (network.reliableOrdered.isConnected()) return;

  return new Promise((resolve) => {
    const check = () => {
      if (network.reliableOrdered.isConnected()) {
        resolve();
      } else {
        setTimeout(check, 50);
      }
    };

    check();
  });
}

await waitForConnection();

// Send a JSON-encoded packet
network.reliableOrdered.sendData(new TextEncoder().encode(JSON.stringify({ hello: "world" })));

// Receive raw server packets sent on this channel
const latestPackets = network.reliableOrdered.getReceivedPackets();

// Decode packets if encoded as JSON
const decodedPackets = latestPackets.map((packet) => {
  return JSON.parse(new TextDecoder().decode(packet));
});
```
