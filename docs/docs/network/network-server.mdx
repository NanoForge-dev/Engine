# Server Networking (network-server)

This document explains the `network-server` package implementation and the APIs used from server-side code.

## Overview

The server listens on configured ports and accepts client connections. A single server process can accept many clients, and typical responsibilities in a game are:

- Accept reliable control messages from clients on `reliableOrdered` and
  `reliableUnordered`, carried by a TCP WebSocket.
- Optionally establish `RTCPeerConnection`s via WebSocket signaling for
  `unreliableOrdered` and `unreliableUnordered`, carried by WebRTC data
  channels, for low-latency state updates.

See [Packet Channels](packet-framing) for what each channel guarantees.

## Client identification

Every client gets a `ClientId`: a random string (UUID) shared by the TCP and UDP
transports.

1. The first transport a client opens starts a session. The server answers with a
   `welcome` message carrying the id and a secret session token (a text frame on
   TCP, where game data is always binary, and a JSON message on the UDP signaling
   socket).
2. The client presents that token (`?token=...`) when it opens its other
   transport, which joins the same session. An unknown token, or a second
   connection on a transport the session already has, is rejected with `401`.
3. The session ends when its last transport closes.

A page reload opens a new session, with a new `ClientId`.

```javascript
network.clients.onConnect((info) => {
  console.log(`${info.id} joined from ${info.transports.tcp?.address}`);
});

network.clients.onDisconnect((info) => {
  console.log(`${info.id} left`);
});

// Anytime: what is known about a client
const info = network.clients.get(clientId);
```

`onConnect` fires as soon as the first transport is up, so when both transports
are used, UDP may not be linked yet.

## Example

It works the same on every channel:

```javascript
// Send everybody a JSON-encoded packet
network.reliableOrdered.sendToEverybody(
  new TextEncoder().encode(JSON.stringify({ type: "are you here" })),
);

// Check the clients reachable on this channel (ClientId strings)
const connectedClients = network.reliableOrdered.getConnectedClients();

// Receive all packets sent on this channel
const allPackets = network.reliableOrdered.getReceivedPackets();

// Get first client packets
const firstClientPackets = allPackets.get(connectedClients[0]);

// Decode packets if encoded as JSON
const decodedPackets = firstClientPackets.map((packet) => {
  return JSON.parse(new TextDecoder().decode(packet));
});
```
