# network-client API

`NetworkClientLibrary` is exposed on `ctx.network`. Its methods take an optional
`{ channel }` to pick one of the four [channels](packet-framing):
`Channel.ReliableOrdered`, `Channel.ReliableUnordered`,
`Channel.UnreliableOrdered` or `Channel.UnreliableUnordered`.

Reliable channels need `SERVER_TCP_PORT` and unreliable ones `SERVER_UDP_PORT`.
Using a channel whose port is not configured throws.

```ts
import { Channel } from "@nanoforge-dev/network/client";

await ctx.network.connect({ channels: [Channel.ReliableOrdered, Channel.UnreliableOrdered] });

ctx.network.sendData({ type: "join" }); // Channel.ReliableOrdered
ctx.network.sendData({ x: 1, y: 2 }, { channel: Channel.UnreliableOrdered });

const messages = ctx.network.getReceivedPackets().map((packet) => packet.json()); // every channel
```

## connect(options?)

Connect to the server and resolve once the channels are open. Only the
transports the channels need are opened: TCP for reliable channels, UDP for
unreliable ones. TCP connects first, then UDP with the TCP session token, so both
share one client id. Calling it again for channels that are already open resolves
right away.

Option `channels`: `Channel[]`, the channels to open and wait for. Every
configured channel by default.

Option `timeout`: `number`, milliseconds before giving up. `10000` by default.

Rejects when a channel's port is not configured, when a transport fails to
connect, or when the channels are not open before the timeout.

Returns: `Promise<void>`

## sendData(data, options?)

Send a payload to the server.

Parameter `data`: [`NetworkPayload`](#networkpayload), bytes, a string or any
JSON value.

Option `channel`: `Channel` to send on. `Channel.ReliableOrdered` by default.

Throws a `TypeError` when `data` cannot be encoded as JSON (`undefined`, a
function).

Returns: `void`

## getReceivedPackets(options?)

Return the packets received since the last call. Call it once per frame.

Option `channel`: `Channel` to read from. Without it, the packets of every
configured channel are returned, reliable channels first.

Returns: [`NetworkData[]`](#networkdata)

## isConnected(options?)

Return `true` when packets can be sent and received.

Option `channel`: `Channel` to check. Without it, every configured channel must
be connected.

Returns: `boolean`

## clientId

Client id assigned by the server, shared by TCP and UDP. `undefined` until
`connect` has been welcomed by the server. It is only kept in memory: a page
reload gets a new id.

Type: `string | undefined`

## NetworkPayload

What `sendData` accepts. Packets carry no format tag: the receiver reads a
packet the way it was sent.

| Value                                              | Encoded as            | Read back with                |
| -------------------------------------------------- | --------------------- | ----------------------------- |
| `Uint8Array`, `ArrayBuffer`, any `ArrayBufferView` | The bytes as they are | `bytes()` or `arrayBuffer()`  |
| `string`                                           | UTF-8 text            | `text()`                      |
| `NetworkData`                                      | Its bytes, unchanged  | What the original sender used |
| Any other value (object, array, number, …)         | `JSON.stringify` text | `json()`                      |

## NetworkData

One received packet. Its methods are synchronous and return a new value on
every call.

| Method          | Returns                                                                    |
| --------------- | -------------------------------------------------------------------------- |
| `bytes()`       | `Uint8Array`: the payload bytes.                                           |
| `arrayBuffer()` | `ArrayBuffer`: the payload bytes.                                          |
| `text()`        | `string`: the payload decoded as UTF-8.                                    |
| `json<T>()`     | `T`: the payload parsed as JSON. Throws a `SyntaxError` if it is not JSON. |
