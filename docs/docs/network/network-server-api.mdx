# network-server API

## ClientId

`string`: an opaque, random identifier (UUID) of a client session. A client
connected over both TCP and UDP has the same `ClientId` on both servers.

## Channel servers

`NetworkServerLibrary` exposes one server per [channel](packet-framing) on
`ctx.network`:

| Property              | Class                       | Needs                |
| --------------------- | --------------------------- | -------------------- |
| `reliableOrdered`     | `ReliableOrderedServer`     | `LISTENING_TCP_PORT` |
| `reliableUnordered`   | `ReliableUnorderedServer`   | `LISTENING_TCP_PORT` |
| `unreliableOrdered`   | `UnreliableOrderedServer`   | `LISTENING_UDP_PORT` |
| `unreliableUnordered` | `UnreliableUnorderedServer` | `LISTENING_UDP_PORT` |

Reading a property whose port is not configured throws. All four classes have
the same methods. Each one only sends and returns the packets of its own
channel.

### channel

The `Channel` this server sends and receives on.

Type: `Channel`

### getConnectedClients()

Return a snapshot array of the clients reachable on this channel: clients with
an open WebSocket for reliable channels, clients with this channel's data
channel for unreliable ones.

Returns: `ClientId[]`

### getClientInfo(clientId)

Return what is known about a client session. See [ClientInfo](#clientinfo).

Parameter `clientId`: `ClientId`

Returns: `ClientInfo | undefined` (`undefined` once the client is gone)

### sendToEverybody(data)

Send a payload to every client reachable on this channel.

Parameter `data`: `Uint8Array` raw payload bytes.

Returns: `void`

### sendToClient(clientId, data)

Send a payload to one client on this channel. Logs an error when the client is
not reachable on it.

Parameter `clientId`: `ClientId` client identifier.

Parameter `data`: `Uint8Array` payload bytes.

Returns: `void`

### getReceivedPackets()

Return the packets each client sent on this channel since the last call. Call
it once per frame.

Returns: `Map<ClientId, Uint8Array[]>`

## clients (`ctx.network.clients`)

Client sessions shared by the TCP and UDP servers. Also available as
`NetworkServerLibrary.clients`.

### get(clientId)

Returns: `ClientInfo | undefined`

### list()

Return every connected client session.

Returns: `ClientInfo[]`

### onConnect(listener)

Call `listener(info)` when a new client session starts, i.e. when its first
transport is up. With TCP and UDP, it fires on TCP open, before UDP is linked:
`sendToClient(info.id)` on an unreliable channel may still report an unknown
client at that point. With UDP only, it fires when the signaling socket opens,
before the data channels exist, so it may also report an unknown client.

Returns: `() => void` that removes the listener.

### onDisconnect(listener)

Call `listener(info)` when a client session ends, i.e. when its last transport
closes.

Returns: `() => void` that removes the listener.

## ClientInfo

| Field         | Type                                             | Description                                       |
| ------------- | ------------------------------------------------ | ------------------------------------------------- |
| `id`          | `ClientId`                                       | Session identifier.                               |
| `connectedAt` | `number`                                         | Timestamp (ms) of the first transport connection. |
| `transports`  | `{ tcp?: ConnectionInfo; udp?: ConnectionInfo }` | Transports currently attached (live object).      |

## ConnectionInfo

| Field         | Type                     | Description                                                 |
| ------------- | ------------------------ | ----------------------------------------------------------- |
| `transport`   | `"tcp" \| "udp"`         | Transport of this connection.                               |
| `address`     | `string`                 | Remote address.                                             |
| `port`        | `number`                 | Remote port.                                                |
| `family`      | `string`                 | `"IPv4"` or `"IPv6"`.                                       |
| `userAgent`   | `string \| undefined`    | `User-Agent` header of the upgrade request.                 |
| `origin`      | `string \| undefined`    | `Origin` header of the upgrade request.                     |
| `params`      | `Record<string, string>` | Query parameters of the upgrade request, without the token. |
| `connectedAt` | `number`                 | Timestamp (ms) of the upgrade request.                      |

`Cookie` and `Authorization` headers are never recorded.
