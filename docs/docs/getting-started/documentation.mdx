---
title: "Documentation"
icon: "book"
description: "How the engine documentation is written and published"
---

The engine documentation lives in the engine repository and is published to this site automatically at each engine release.

- **Pages** are the `.mdx` files in `docs/docs`. Their order and groups come from `docs/docs/navigation.json`: every page is listed there exactly once.
- **API references** are generated from the TSDoc comments of each package by `pnpm run docs` (TypeDoc), into `docs/references`. They are never written by hand.

To change a page, edit it in the engine repository. Links between pages are relative to the file, like `./how-to-use` or `../network/index`.
