# network-client API

`NetworkClientLibrary` exposes one client per [channel](packet-framing) on
`ctx.network`:

| Property              | Class                       | Needs             |
| --------------------- | --------------------------- | ----------------- |
| `reliableOrdered`     | `ReliableOrderedClient`     | `SERVER_TCP_PORT` |
| `reliableUnordered`   | `ReliableUnorderedClient`   | `SERVER_TCP_PORT` |
| `unreliableOrdered`   | `UnreliableOrderedClient`   | `SERVER_UDP_PORT` |
| `unreliableUnordered` | `UnreliableUnorderedClient` | `SERVER_UDP_PORT` |

Reading a property whose port is not configured throws.

The library connects during `__init`: TCP first, then UDP with the TCP session
token, so both transports share one client id. Each connection resolves once the
server's `welcome` is received, or gives up after 5 seconds. A transport that
fails to connect is logged and does not fail initialization.

## Channel clients

All four classes have the same methods. Each one only sends and returns the
packets of its own channel.

### channel

The `Channel` this client sends and receives on.

Type: `Channel`

### getClientId()

Return the client id assigned by the server, once welcomed.

Returns: `string | undefined`

### isConnected()

Return `true` when packets can be sent and received on this channel: the
WebSocket is open for reliable channels, the channel's data channel is open for
unreliable ones. Data channels may open shortly after `__init` resolves.

Returns: `boolean`

### sendData(data)

Send a payload to the server on this channel.

Parameter `data`: `Uint8Array` raw payload bytes.

Returns: `void`

### getReceivedPackets()

Return the packets received on this channel since the last call. Call it once
per frame.

Returns: `Uint8Array[]`

## Channel

Enum of the four channels: `Channel.ReliableOrdered`,
`Channel.ReliableUnordered`, `Channel.UnreliableOrdered` and
`Channel.UnreliableUnordered`.

## clientId (`ctx.network.clientId`)

Client id assigned by the server, shared by TCP and UDP. `undefined` until a
transport has been welcomed. It is only kept in memory: a page reload gets a new
id.
